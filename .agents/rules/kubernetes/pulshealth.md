# PulsHealth

`kubernetes/pulshealth/upstream/` is generated by `./render` from the upstream
release the app images run. Don't edit it by hand.

## Updating the TimescaleDB image

The image must equal the TimescaleDB image upstream's
`server/docker-compose.yml` runs the database with for the release;
renovate-eval flags a release that changes it (`.renovate-eval.md`, PulsHealth
Updates). These steps cover an image on the same PostgreSQL major. A new major
isn't covered; work out how to upgrade before taking one. Update the image in
`imagecatalog.yaml` and the migrate init container in `deploy.yaml`. Once CNPG
has restarted on it, update the extension with no app connected:

```bash
kubectl -n pulshealth scale deploy pulshealth --replicas=0
kubectl -n pulshealth exec pulshealth-postgres-1 -c postgres -- psql -X -d pulshealth -c "ALTER EXTENSION timescaledb UPDATE"
kubectl -n pulshealth scale deploy pulshealth --replicas=1
```
